Set up with a GitHub key instead

Only needed if signing in stops working. This editor needs a key from your GitHub account.

  1. Open GitHub's new key page (you need to be signed in to GitHub as mahalakshmirajagopal).
  2. Name it Website editor and set Expiration to No expiration.
  3. Under Repository access, choose Only select repositories and pick mahalakshmirajagopal.github.io.
  4. Under Permissions, click Add permissions, choose Contents, and set it to Read and write.
  5. Click Generate token, copy the long code that starts with github_pat_, and paste it below.
